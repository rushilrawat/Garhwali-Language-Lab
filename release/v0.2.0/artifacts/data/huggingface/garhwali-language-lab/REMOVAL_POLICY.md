# Data correction and removal policy

Rights holders, speakers, contributors, and community members can request a
correction, attribution change, access restriction, or removal by opening an
issue in the project repository. Include the record ID or source ID, the requested
change, and enough evidence to identify the affected material without posting
private information publicly.

A confirmed request is recorded as a versioned provenance decision. Public
packages are rebuilt so the affected content is removed or redacted while its
non-sensitive audit identity and the reason for the change remain documented
where appropriate.
