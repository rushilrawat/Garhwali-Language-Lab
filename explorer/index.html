Garhwali Corpus Explorer

Browse the public Garhwali (gbm) datasets from the Garhwali Language Lab. Each row keeps its source, license, rights and quality fields. Data is read live from the Hugging Face Dataset Viewer API.

Row totals are view counts. Configurations overlap, and reference tables (record_index, record_sources, source_catalog) are not language examples. Rows are automatically screened, not native-speaker reviewed. Check each row's license and rights fields before reuse.
