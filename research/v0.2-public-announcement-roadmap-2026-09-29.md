# v0.2.0 public announcement readiness roadmap

**Purpose:** prepare a concise, accurate public announcement for the Garhwali Language Lab v0.2.0 corpus release. This roadmap covers verification, documentation alignment, disclosure, and a review-ready LinkedIn draft. It does not declare the benchmark public or the models independently validated.

**Time budget:** 2–4 focused hours end to end. The initial live-page and local-test checks below are already complete; allow about 1–2 focused hours for the remaining documentation reconciliation, last-minute link check, and final post review, provided no count or availability discrepancy appears.

**Status as of 2026-09-29:** the GitHub v0.2.0 release and both public Hugging Face dataset pages resolve; the corpus and speech Viewers load. The README and documentation index are reconciled in the local working tree, and test/link/diff checks pass. The documentation update has not yet been pushed. The post is prepared below; the user must review its exact wording before publication.

## What “good enough to announce” means

The announcement may describe a released, provenance-preserving Garhwali corpus and its companion speech resource. It must distinguish source rows from unique examples, describe the public text package as rights-filtered, and label machine-generated transcript drafts and automated language/model results accurately. It must not claim that every collected work is publicly downloadable, that the corpus is native-validated, that the benchmark is cleared for public release, or that a new independent model gain has been demonstrated.
